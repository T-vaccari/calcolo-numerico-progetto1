# Progetto 1 - Calcolo Numerico in MATLAB

Repository del primo progetto MATLAB su sistemi lineari, fattorizzazione LU e metodi iterativi per la risoluzione numerica.

## Contenuto

- `Progetto1.m`: script principale del progetto.
- `helper/`: funzioni di supporto usate dallo script.
- `risultati/`: relazione finale prodotta in LaTeX.

Il testo originale della consegna è conservato soltanto in locale e non fa parte del repository pubblico.

## Esecuzione

Aprire MATLAB nella root della repository ed eseguire:

```matlab
Progetto1
```
